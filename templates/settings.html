Safety rules

How the Global Period Behaves

Default, not a lock

The active period is selected automatically, but staff can intentionally choose a historical period where a page allows it.

Existing data stays untouched

Changing the active term does not move old attendance, CA/Test, essay or result records into another term.

Local saves first

The local setting is committed immediately. Cloud synchronization follows through the durable EMIS queue when Internet is available.

Exam push remains protected

Class-specific pushed exam year/term remains authoritative for a live student exam so a global default cannot misfile an examination.
