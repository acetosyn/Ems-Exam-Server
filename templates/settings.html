Result Pipeline

How Results Save

1
Student submits exam

Exam Server calculates the raw percentage score.

2
Score converts to /70

The report-sheet exam score is saved as 70% maximum.

3
Supabase receives result

Student, class, subject, session, term and time are saved.

4
Staff software reads it

CA/Test scores are added before report generation.

Important Rules

Result Saving Rules

Admission number is the main key

Names can repeat, but admission numbers identify students correctly.

One result per subject per term

A student should not have duplicate subject results for one term.

Local + Supabase saving

CSV/Excel remains while Supabase becomes the shared bridge.

Backend only

The Supabase service key must never enter frontend JavaScript.
