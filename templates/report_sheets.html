Generation Rules

Report Sheet Requirements

Rules used by the EMIS report generation engine.

Students come from the EMIS roster Active students are loaded from students2026.csv using the selected class level and arm.
Students can be selected Use the student checkboxes to generate one or several selected report sheets.
Assessment source Configured assessment records are matched to students and subjects using their admission numbers and academic context.
EMIS examination results Existing EMIS examination results are merged with the configured assessment scores during report generation.
Subject statistics POS, OUT OF, LOW, HIGH and CLASS AVE are calculated from the complete class result set.
Attendance Days open, attendance score and attendance percentage are fetched from saved term attendance records.
Remarks are editable Teacher remark, principal remark, affective traits and psychomotor ratings can be edited before printing.
Portrait report sheet Generated report sheets use the new parent-friendly A4 portrait layout for printing and PDF export.
